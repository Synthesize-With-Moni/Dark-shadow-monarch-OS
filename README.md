## Build on GitHub
1. Create or open a GitHub repository.
2. Upload the contents of this project (not the outer ZIP folder).
3. Push to `main`/`master`, or open **Actions → Build Shadow System APK → Run workflow**.
4. Wait for the workflow to finish.
5. Open the successful run → **Artifacts** → `ShadowSystem-final-apk`.
6. Download `app-debug.apk` to Android and install it.

The workflow uses Android SDK setup v4, Java 17, Android 35, and Gradle 8.7.
